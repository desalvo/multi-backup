Vault backup anti-ransomware

Lato server: copia cifrata verificabile dello store Multi Backup in uno storage separato. Ogni versione è nuova; nessuna API di delete o overwrite. Protezione ransomware effettiva solo con WORM/append-only applicato fuori dal processo.

Il restore richiede l’autorizzazione offline già presente nella sezione esportazione. Non scrive mai sullo store originale.

Notifiche SMTP(S)

Il server può inviare un messaggio di prova al destinatario configurato. La password viene letta da un Secret separato; TLS e certificato server sono obbligatori.

Esportazione selettiva

In modalità protetta, il ripristino richiede l'accesso amministrativo e un codice di approvazione indipendente, che non viene salvato dal browser.

Non condividere il codice di recupero con gli altri utenti. Il server non espone mai il vault.

Seleziona un singolo file o una cartella. Il restore viene verificato e scritto in una nuova directory sul server, senza sovrascrivere l'origine.
